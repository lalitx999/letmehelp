# Let Me Help — เว็บคอร์สเรียนออนไลน์

Django 6 + Bootstrap 5.3 (local, ไม่ใช้ CDN) + PostgreSQL + Celery/Redis

## รันในเครื่อง

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # แล้วแก้ค่า (SECRET_KEY, DATABASE_URL ฯลฯ)
createdb letmehelp
python manage.py migrate
python manage.py seed_demo      # หมวด/คอร์สตัวอย่าง + บัญชีทดสอบ (รหัสผ่านอยู่ใน .seed_credentials)
python manage.py runserver
```

ตอนพัฒนา (`config.settings.local`) Celery รันแบบ eager จึง **ไม่ต้องมี Redis**

## โครงสร้าง (Service / Selector Layer)

| App | หน้าที่ |
|---|---|
| `accounts` | User (ล็อกอินด้วยอีเมล, ชื่อ, เบอร์โทร) |
| `courses` | หมวด, คอร์ส, บท, คลิป YouTube, PDF ประกอบ |
| `enrollments` | สิทธิ์เรียน + อายุคอร์ส + ต่ออายุ |
| `payments` | ออเดอร์, สลิป, QR PromptPay, ตรวจสลิป EasySlip (Celery) |
| `learning` | หน้าเรียน, จำตำแหน่งวิดีโอ (ถอย 10 วินาที), ปฏิทิน/สถิติ |
| `notifications` | อีเมลแจ้งหมดอายุ (Celery beat), แจ้งเตือนแอดมินทาง Telegram |
| `dashboard` | Custom Admin (`/dashboard/`), รายงาน PDF/Excel |

แต่ละ app: `services/` (logic หลายขั้นตอน) · `selectors/` (query) · `views.py` (รับ → เรียก service → ตอบ)

## Production

### Deploy ขึ้น VPS (โฟลเดอร์ `deploy/`)

1. ครั้งแรก บน VPS: อัปโหลด `deploy/` แล้วรัน `sudo bash deploy/setup_server.sh โดเมน.com`
   — ติดตั้ง PostgreSQL/Redis/Nginx/firewall/swap, สร้าง `.env` พร้อม SECRET_KEY และรหัส DB แบบสุ่ม (บนเครื่องนั้นเท่านั้น), ลง systemd 3 ตัว
2. จาก Mac: `bash deploy/push.sh` — เทส → rsync เฉพาะโค้ด (ไม่ส่ง .env/ไฟล์ลูกค้า) → migrate/collectstatic/check → restart → health check
3. HTTPS: `sudo certbot --nginx -d โดเมน.com -d www.โดเมน.com --redirect`
4. ดู log: `journalctl -u letmehelp-web -f` (และ `letmehelp-worker`, `letmehelp-beat`)

### คำสั่งที่ systemd ใช้

```bash
DJANGO_SETTINGS_MODULE=config.settings.production python manage.py collectstatic --noinput
# ASGI (แนะนำ): แชทบอทเป็น async view — ระหว่างรอ Claude worker ไปรับคำขออื่นได้
gunicorn config.asgi:application -k uvicorn_worker.UvicornWorker --workers 3 --bind 127.0.0.1:8000
# (ยังรันแบบ WSGI ได้: gunicorn config.wsgi:application — ทำงานถูกต้องแต่การรอ AI จะกิน worker 1 ตัวต่อคำขอ)
celery -A config worker -l info
celery -A config beat -l info      # ตัวตั้งเวลาแจ้งเตือนหมดอายุ
```

- ตั้ง `DJANGO_SETTINGS_MODULE=config.settings.production` ใน service/env, `DEBUG=False` ถูกบังคับในไฟล์นั้น
- `/django-admin/` (Django admin หน้าเดิม) **ปิดใน production** — แอดมินใช้ `/dashboard/` เปิดชั่วคราวได้ด้วย `DJANGO_ADMIN_ENABLED=True`
- Celery worker/beat ใช้ settings production เป็นค่าเริ่มต้นแล้ว (เหมือน wsgi/asgi)
- Nginx เสิร์ฟ `/static/` (`staticfiles/`) และ `/media/` (`media/`) โดยตรง หรือใช้ WhiteNoise ที่เปิดไว้แล้ว
- **`private_media/` ห้ามเสิร์ฟผ่าน Nginx** (สลิป, PDF ประกอบการเรียน, รายงาน) — Django ตรวจสิทธิ์ก่อนส่งไฟล์
- PDF ภาษาไทย: ตั้ง `PDF_FONT_PATH` เป็นไฟล์ .ttf (เช่น Sarabun/Noto Sans Thai) บน server

## ข้อตกลงกับลูกค้า (ธุรกิจ)

- **ขายคอร์สจ่ายครั้งเดียว เรียนได้ 365 วัน** ไม่มีต่ออายุฟรีอัตโนมัติ — ก่อนหมดอายุระบบส่งอีเมลเตือน 30/7/1 วัน (แก้ได้ที่ ตั้งค่าเว็บ) พร้อมลิงก์ต่ออายุแบบชำระเงิน แอดมินยังต่ออายุให้รายคนเองได้จากหน้า สิทธิ์เรียน
- **ราคา:** TGAT/A-Level 1,490 บาท · **โปรเปิดตัว 990 บาท** ตั้งที่หน้าแก้ไขคอร์ส (ราคาโปรโมชัน + วันสิ้นสุด) ใช้ได้ถึงสิ้นวันนั้นแล้วกลับเป็นราคาปกติเอง ออเดอร์เก็บราคา ณ ตอนสั่ง ถ้าหมดโปรระหว่างที่นักเรียนกำลังโอน ออเดอร์ที่สั่งไว้แล้วยังคิดราคาโปร
- **แจ้งเตือนแอดมินด้วย Telegram** (สมัครใหม่ / ส่งสลิป / ชำระแล้ว / สลิปรอตรวจ) แทน LINE OA เพราะฟรีไม่จำกัดข้อความ: สร้างบอทกับ @BotFather → ใส่ `TELEGRAM_BOT_TOKEN` → ให้แอดมินกด Start กับบอทแล้วใส่ chat id ใน `TELEGRAM_CHAT_IDS` (หลายคนคั่นด้วยจุลภาค) ถ้ายังไม่ตั้งระบบข้ามการแจ้งเตือนเงียบๆ
- **ถามก่อนซื้อ:** ปุ่มทักไปที่ LINE ส่วนตัวของเจ้าของ (ตั้งลิงก์ที่ ตั้งค่าเว็บ → ลิงก์ LINE) ไม่ใช้ LINE OA
- **หนังสือ:** PDF แนบกับบทเรียนในคอร์ส · หนังสือเล่มจริงขายผ่าน Shopee ใส่ลิงก์ที่หน้าแก้ไขคอร์ส จะมีปุ่ม "สั่งซื้อหนังสือเล่ม" ในหน้าคอร์ส
- ใบเสร็จ/บิลออกนอกระบบ (เจ้าของยังเป็นบุคคลธรรมดา ไม่มีหัก ณ ที่จ่าย)

## PWA · คุกกี้ · นโยบาย · Footer

- **PWA:** ติดตั้งเป็นแอปได้ (manifest + service worker + หน้าออฟไลน์ที่ไม่มีข้อมูลผู้ใช้) ปุ่ม "ติดตั้งแอปบนมือถือ" อยู่ใน Footer (Android/Chrome กดติดตั้งได้เลย, iPhone แสดงวิธีเพิ่มไปหน้าจอโฮม) ต้องเสิร์ฟผ่าน **HTTPS** บน production ถึงจะติดตั้งได้ · service worker cache เฉพาะไฟล์ static + หน้าออฟไลน์ ไม่ cache หน้าที่มีข้อมูลผู้ใช้หรือวิดีโอ
- **คุกกี้:** แบนเนอร์ขึ้นครั้งแรกที่เข้าเว็บ (ยอมรับทั้งหมด / เฉพาะที่จำเป็น) จำตัวเลือก 180 วันใน cookie `lmh_consent` เปลี่ยนได้ที่ลิงก์ "ตั้งค่าคุกกี้" ใน Footer ตอนนี้เว็บไม่มีคุกกี้วิเคราะห์/โฆษณา (YouTube เล่นผ่านโดเมน nocookie) ถ้าจะเพิ่ม Analytics ภายหลัง ให้โหลดสคริปต์เฉพาะเมื่อ `LMH.consent.allows("analytics")` เป็นจริง
- **นโยบายความเป็นส่วนตัว (`/privacy/`) และข้อกำหนดการใช้งาน (`/terms/`):** ร่างตาม PDPA และกติกาของเว็บนี้ ชื่อผู้ให้บริการ/อีเมลติดต่อ/โซเชียลตั้งที่ ตั้งค่าเว็บ ในหลังบ้าน **ควรให้ลูกค้า (หรือที่ปรึกษากฎหมาย) อ่านและยืนยันก่อนเปิดจริง โดยเฉพาะเรื่องคืนเงิน** แก้วันที่ใน `POLICY_UPDATED` (`apps/core/views.py`) ทุกครั้งที่ปรับเนื้อหา
- **สมัครสมาชิก:** ต้องติ๊กยอมรับข้อกำหนดและนโยบาย ระบบเก็บเวลาที่ยอมรับไว้ที่ `User.terms_accepted_at`
- **Footer:** โครงมาตรฐาน (แบรนด์ + โซเชียล + คอลัมน์ลิงก์ + ลิขสิทธิ์) ไอคอน Facebook/Instagram/YouTube/TikTok/LINE/อีเมลจะโผล่เองเมื่อกรอกลิงก์ในหน้า ตั้งค่าเว็บ

## หลังบ้าน (`/dashboard/`)

แอดมินระดับเดียว (`is_staff`) ทำได้ทุกอย่าง ใช้ธีมเดียวกับเว็บ รองรับมือถือ (ตารางแปลงเป็นการ์ด) กด `/` เพื่อไปช่องค้นหา

| กลุ่ม | หน้า | ทำอะไรได้ |
|---|---|---|
| การสอน | คอร์ส, หมวดคอร์ส | เพิ่ม/แก้/ลบ/ทำสำเนา/สลับเผยแพร่-แนะนำ/ทำหลายรายการ · บท คลิป ไฟล์แนบ แพ็กเกจราคา (modal + เลื่อนลำดับ) |
| ผู้ใช้ | นักเรียน, สิทธิ์เรียน | สร้าง/แก้/ปิดบัญชี/รีเซ็ตรหัส/โน้ตแอดมิน · มอบ-ต่ออายุ-ยกเลิก-กู้คืนสิทธิ์ ส่งอีเมลเตือน |
| การเงิน | ออเดอร์, ตรวจสลิป, รายงาน | สร้างออเดอร์เอง/ทำเครื่องหมายว่าจ่ายแล้ว/ยกเลิก/คืนเงิน · ดูสลิปและผลตรวจ · รายงาน PDF/Excel |
| ระบบ | ผู้ดูแลระบบ, ตั้งค่าเว็บ, ประวัติการแก้ไข, ถังขยะ | จัดการแอดมิน (ปิดตัวเอง/แอดมินคนสุดท้ายไม่ได้) · PromptPay, LINE, วันเตือน, ประกาศบนเว็บ (คีย์ลับยังอยู่ใน `.env`) · ดูว่าใครทำอะไรเมื่อไหร่ · กู้คืน/ลบถาวร |

- **ถังขยะ:** ลบคอร์ส/หมวด/บท/คลิป = ซ่อนไว้ (soft delete) กู้คืนได้ ลบถาวรได้เฉพาะจากหน้าถังขยะ (ยืนยัน 2 ชั้น) และบล็อกถ้าคอร์สยังมีนักเรียน/ออเดอร์ผูกอยู่ คอร์สที่ถูกลบ/เลิกเผยแพร่ นักเรียนที่ซื้อแล้วยังเรียนต่อได้
- **ประวัติการแก้ไข (`AuditLog`):** บันทึกจาก service ทุกครั้งที่สร้าง/แก้/ลบ/อนุมัติ/คืนเงิน/มอบสิทธิ์ พร้อมผู้ทำ (หรือ "ระบบ (EasySlip)") แก้ลบไม่ได้จากหน้าเว็บ

## UI / ดีไซน์

ดีไซน์ v2 "Frosted mono" ได้แรงบันดาลใจด้านโครงหน้า (หัวข้อกลางจอ + การ์ดลอย, ส่วนพื้นเข้มที่มีการ์ดขาวซ้อน, ปุ่มเม็ดยา) จากหน้า fastwork.com/th/selling โดยเขียนใหม่ทั้งหมดด้วย Bootstrap 5.3 local ไม่ได้คัดลอกโค้ด รูป หรือข้อความของเขา
- โทน: ขาว · ดำ · เทา + กระจกเบลอ (`.glass`, `backdrop-filter`) และแสงฟุ้งสีโลโก้จางๆ (`.glow.red/.blue/.orange`) ใช้แดงโลโก้เป็นสีเน้นเท่านั้น
- หัวข้อสองโทน: ใส่ `<span class="soft">` ในบรรทัดแรกให้เป็นสีเทา · ป้ายเล็ก `.lbl` = เม็ดยาจุดแดง
- ส่วนประกอบหน้าแรก: `.hero` + `.floaters`, `.tiles`, `.night` + `.sheet` + `.feat`, `.steps`, `.accordion.is-cards`, `.cta-end`
- ปุ่มเพิ่ม: `.btn-glass` (ขาวกระจก), `.btn-white` และ `.btn-ghost-light` (ใช้บนพื้นเข้ม)
- Design tokens และ component ทั้งหมดอยู่ใน `static/css/site.css` (ไม่ใช้อิโมจิ ใช้ไอคอนล้วน)
- ไอคอน: Bootstrap Icons (MIT) แบบ sprite เฉพาะที่ใช้ที่ `static/vendor/bootstrap-icons/icons.svg` ใช้ใน template ด้วย `{% icon "ชื่อไอคอน" %}` (ต้อง `{% load ui %}`) ถ้าต้องการไอคอนเพิ่ม เพิ่มชื่อใน `scripts/build_icons.py` แล้วรันสคริปต์ใหม่
- ฟอนต์: Sarabun (SIL OFL) อยู่ใน `static/fonts/` ใช้ทั้งหน้าเว็บและ PDF
- ตอนพัฒนามี middleware ปิด cache ของ `/static/` และ service worker ใช้ network-first (ถ้าเปิดแล้วเห็น CSS เก่า ให้ unregister service worker ใน DevTools)

## ฟีเจอร์ที่เรียนรู้จาก ryu_new และนำมาปรับใช้

- **แพ็กเกจราคาตามอายุ** (`CoursePackage`): แพ็กเกจหลักคือ `Course.price` + `access_days` เพิ่มตัวเลือก 1 ปี/ตลอดชีพ (36500 วัน) ได้ในแดชบอร์ด หน้าชำระเงินให้เลือกแพ็กเกจ ออเดอร์เก็บราคาและอายุไว้ ณ ตอนสั่งซื้อ
- **ตรวจสลิป:** อ่านเลขบัญชี/พร็อกซีผู้รับจาก response ของ EasySlip หลายรูปแบบ ยอดหรือผู้รับไม่ตรงถือว่า "น่าสงสัย" ส่งเข้าคิวแอดมินตัดสินพร้อมเหตุผล (ไม่ปฏิเสธอัตโนมัติ) ส่วนสลิปซ้ำ/อ่านไม่ได้ปฏิเสธทันที
- **สมุดโน้ตส่วนตัวในหน้าเรียน:** บันทึกอัตโนมัติ แทรกเวลา `[mm:ss]` คลิกเวลาเพื่อข้ามวิดีโอ คัดลอก/ดาวน์โหลด .txt
- **ทดลองเรียนฟรี** (`/free-trial/`) ดูคลิปตัวอย่างได้โดยไม่ต้องล็อกอิน และ **คู่มือการเรียน** (`/guide/`)
- **สถิติ:** เพิ่มจำนวนวันต่อเนื่องสูงสุด เวลาเรียนเดือนนี้ และแจ้งเตือนเมื่อวันนี้ยังไม่ได้เรียน
- **แดชบอร์ด:** หน้า "สิทธิ์เรียน / ใกล้หมดอายุ" ส่งอีเมลเตือนต่ออายุรายคนได้

## แดชบอร์ดนักเรียนและหน้าเรียน (ปรับตามที่ดูจาก ryu_new)

- **แดชบอร์ด** (`/learn/my-courses/`): ส่วนหัวมีข้อมูลผู้เรียน ปุ่มหลัก "เลือกคอร์สเพิ่ม / ต่ออายุ" มุมขวา ปุ่มเรียนต่อ การ์ดคอร์สพร้อมความคืบหน้า และคอลัมน์ข้าง: streak + แถบ 7 วัน, ปฏิทิน, แก้ข้อมูลส่วนตัว/เปลี่ยนรหัสผ่าน, ช่วยเหลือ
- **หน้าเรียน**: แถบหัวคอร์ส (ความคืบหน้า วันหมดอายุ ต่ออายุ), วิดีโอ + แถบปุ่ม (ย้อน/ข้าม 10 วินาที, ความเร็ว, จดโน้ต, เต็มจอ), ปุ่มคลิปก่อนหน้า/ถัดไป, แท็บสมุดโน้ต/เอกสาร และสารบัญที่พับได้บนมือถือ

## แชทบอทลอย

ปุ่ม "ถามผู้ช่วย" มุมขวาล่างทุกหน้า (ยกเว้นแดชบอร์ดแอดมิน) — `apps/chatbot`
- **โหมดทั่วไป**: ตอบเรื่องคอร์ส ราคา แพ็กเกจ การชำระเงิน วิธีเรียน โดยดึงราคาจากฐานข้อมูลจริง (แคช 5 นาที)
- **โหมดติวเตอร์**: ในหน้าเรียน (เฉพาะคนที่มีสิทธิ์คลิปนั้น/คลิปฟรี) ช่วยอธิบายเนื้อหา ไม่ชวนซื้อ
- **ตั้งค่า `ANTHROPIC_API_KEY`** ใน `.env` เพื่อใช้ Claude (ค่าเริ่มต้น `claude-opus-5-5`, effort `low`, มีโมเดลสำรองเมื่อถูกปฏิเสธ) — ถ้าไม่ตั้ง หรือเรียกไม่สำเร็จ จะใช้บอทกติกาที่ตอบจากข้อมูลจริงในระบบ (ฟรี)
- จำกัดการใช้งาน 20 ข้อความ/10 นาที ต่อผู้ใช้หรือ IP, ประวัติ 10 ข้อความ, ข้อความละ 800 ตัวอักษร เพื่อคุมค่าใช้จ่าย
- เปลี่ยนโมเดลที่ถูกลงได้ด้วย `CHATBOT_MODEL` (เช่น `claude-sonnet-5-5`, `claude-haiku-5-5`) และใส่ `LINE_CONTACT_URL` เพื่อแสดงปุ่มคุยกับแอดมินทาง LINE
